## Для Claude Code

- Крупные фичи (новая сцена, глава, система) начинай в plan mode: план, потом моё «да», потом код.
- Испанские тексты после написания отдавай агенту `spanish-editor`, новый лор — агенту `lore-keeper`.
- Визуальные изменения проверяй глазами: Playwright MCP или скриншоты из `tests/screenshots/`.
- Файлы в `dist/` генерируются сборкой. Правь только `src/`.
