### 1. ~~Остатки режима с ходьбой~~ — закрыто гибридом

Код ходьбы больше не «остаток»: он работает на улицах в основном режиме (`src/modes/walk/`, `Player.move`, коллайдеры `SceneManager`, камеры по зонам). В «Modo lectura» он не используется. См. п. 2а и [ARCHITECTURE](ARCHITECTURE.md#гибрид-улица-и-кадры-два-режима-игры).

### 2. ~~Глобальная область видимости → ES-модули~~ — сделано

ES-модули с явными `import`/`export`, esbuild, по-прежнему один HTML на версию (см. [ARCHITECTURE](ARCHITECTURE.md#обзор)). Следующий шаг — общий код в `src/shared/` и гибрид ходьбы и кадров.

### 2а. Гибрид ходьбы и кадров — сделано (ветка `feature/hybrid`)

Целевая версия — одна сборка на `/`. У каждой сцены `mode: 'walk' | 'frame'`; `Game` при смене сцены переключает ввод, камеру, HUD и активные точки.

- **walk** (свободная ходьба): callejón, plaza, pasaje (погоня в реальном времени, «no mires atrás»), подход к puerta.
- **frame** (статичный кадр с активными точками): tienda, quiosco вблизи, cabina, banco (Anselmo), pedestal.
- Вход в кадр — дверь/триггер или клик/`E` по объекту, с затемнением; выход возвращает на улицу в точку входа.
- Тач в walk-сценах: тап по земле — герой идёт к точке (простой обход коллайдеров); джойстик — опция.
- Режимы — настройки одного рантайма: «Modo: normal» (гибрид, по умолчанию) и «Modo lectura» (все сцены — кадры; погоня через выборы на время, `chaseSeq`). Текущие сборки (квест, ходьба) получаются как частные случаи.
- Одно сохранение на гибрид (`v: 2`) с миграцией из сохранений квеста и ходьбы.
- Перед началом поставлен тег `v0.2-pre-hybrid`.
- Сделано: ESM + esbuild → `src/shared/` + `characters.js` → сцены с `mode` и гибрид → тесты и документация. Следующее: персонажи «из сна» (`src/shared/characters.js`: параметрические low-poly тела, «эффект сна» в постпроцессе, настройка «Efecto de sueño»).

### 3. Тестирование на реальных устройствах

Не проверено в реальном Safari (macOS/iOS) и на реальных Android-устройствах. Риски: Web Audio на iOS (разблокировка жестом, `webkitAudioContext`), `speechSynthesis` (наличие голоса es-ES), производительность WebGL на слабых GPU, `localStorage` для `file://` в Safari, безопасные зоны (`env(safe-area-inset-*)`).

### 4. Прочее

- Прохождение e2e длится ~10 минут из-за таймеров погони и кат-сцен в реальном времени. Возможное ускорение — множитель времени только для тестов.
- Флаг `doc_periodico2` выставляется, но нигде не читается.
- Журнал решений (`state.decisions`) накапливается, но не показывается в интерфейсе.
- Уровни A2–B1 из концепции не реализованы — задача следующих глав.
