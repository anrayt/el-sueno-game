# EL SUEÑO — правила проекта

Браузерный психологический хоррор для изучения испанского. Глава I «La Ciudad Vacía» готова, следующая — II «El Hospital». Подробности в `docs/`: ARCHITECTURE, GAME_DESIGN, LORE, LANGUAGE_DESIGN, CONTENT_GUIDE, DEPLOY. Прочитай нужный документ перед работой в его области.

## Команды

- `npm run build` — собрать игру в `dist/el-sueno.html` (общий код — `src/shared/`, улица — `src/modes/walk/`, кадры — `src/modes/frame/`)
- `npm test` / `npm run test:mobile` — сквозное прохождение в основном режиме, десктоп / мобильный (`tests/e2e.py`, ~6 мин каждый)
- `npm run test:lectura` — сквозное прохождение в «Modo lectura», десктоп и мобильный (`tests/e2e_lectura.py`, ~10 мин каждый)
- `npm run test:saves` — формат сохранения v2 и миграция старых партий
- `npm run test:all` — всё вышеперечисленное подряд (~35 мин)
- `npm run test:setup` — поставить Playwright и Chromium для тестов
- `npm run build:site` — собрать `site/` для Cloudflare Pages (`index.html`, `_headers`, `_redirects`, `404.html`)
- Перед тем как сказать «готово», запусти сборку и нужный e2e. Если тест не запускался, так и скажи.

## Одна игра — два режима

- Одна сборка. «Modo: normal» (по умолчанию): на улицах — ходьба (WASD, тап по земле, джойстик как опция), интерьеры, осмотр вблизи и разговоры — кадры с активными точками. «Modo: lectura»: все сцены — кадры, без ходьбы.
- У каждой сцены в `src/shared/scenes.js` есть `mode: 'walk' | 'frame'`; `Game` переключает ввод, камеру, HUD и активные точки.
- Сюжет, тексты, мир, звук и сохранение общие. Любое изменение контента должно работать в обоих режимах. Код ходьбы и код кадров не удалять.

## Жёсткие правила

1. **Весь внутриигровой текст — только на кастильском испанском.** Это интерфейс, документы, диалоги, подсказки, ошибки. Никакого русского или английского в игре. Комментарии в коде — на любом языке.
2. **Уровень языка соответствует главе:** I — A1 (presente, ser/estar/tener/hay), II — A2 (indefinido/imperfecto), дальше — B1. Новые слова попадают в `LEX` с определением на простом испанском. Перевода на русский в игре нет.
3. **Язык — это механика, а не тест.** Понимание текста должно что-то менять в мире: открывать путь, спасать от угрозы, раскрывать лор. Не делать викторины «выбери перевод».
4. **Один HTML-файл на версию.** Он работает через `file://`, без сети и сервера; Safari и iOS — целевые платформы.
5. **Не ломать сохранения.** Если меняется формат `state`, поднимай `v` и пиши миграцию в `SaveManager.load`. Старые сейвы должны загружаться. Сейчас формат `v: 2` (`SAVE_KEYS.hybrid`); партии v1 квеста и ходьбы наследуются через `SaveManager.migrate`.
6. **Контент — в данных, логика — в системах.** Новые объекты, документы, слова, архив и эхо добавляются через структуры данных (см. `docs/CONTENT_GUIDE.md`), а не через `if` в цикле.
7. **Лор не противоречит себе случайно.** Противоречия допустимы только намеренные: кто-то лжёт или факты трактуются по-разному. Сверяйся с `docs/LORE.md` и обновляй его.
8. **Оригинальность.** Никаких логотипов реальных групп, персонажей, ассетов и музыки из чужих игр. Референсы (Silent Hill, Electric Wizard и т. д.) — только по настроению.
9. **Не пушить, не деплоить и не трогать секреты без явной просьбы.**

## Определение «готово»

Сборка проходит; e2e зелёные; новые сюжетные ветки покрыты тестом; документы в `docs/` обновлены; есть запись в `CHANGELOG.md`.
