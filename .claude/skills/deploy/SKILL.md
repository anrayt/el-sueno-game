name: deploy
description: Выпуск новой версии игры на Cloudflare
disable-model-invocation: true
---

1. Проверь, что ветка — `main`, рабочее дерево чистое, и ты синхронизирован с `origin`.
2. Запусти `npm run test:all` (сборка, квест на десктопе и мобильном, ходьба, сохранения). При любом падении остановись и доложи.
3. Покажи мне, что войдёт в релиз (`git log` от последнего тега) и предложи номер версии и запись в CHANGELOG.
4. **Жди моего подтверждения.**
5. Обнови CHANGELOG, поставь тег `vX.Y.Z`, затем `git push && git push --tags`. Деплой делает GitHub Actions (job `deploy` на push в `main`; e2e идут параллельно и деплой не блокируют).
6. Через `gh run watch` дождись завершения workflow и сообщи результат и адреса: `https://el-sueno.pages.dev/` (квест) и `/walk/` (ходьба).
