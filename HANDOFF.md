Короткая техническая записка от предыдущего разработчика. Полную документацию нужно написать на её основе (см. промт в чате).

## Что это

EL SUEÑO, глава I «La Ciudad Vacía» — браузерный психологический хоррор в формате кинематографичного квеста (Telltale / Snatcher). Игрок не ходит: смотрит на фиксированные 3D-кадры, нажимает на активные точки, читает документы и выбирает реплики. Весь игровой текст на испанском (Испания, уровень A1). Цель — учить испанский через сюжет.

## Сборка

- `npm install` (ставит three@0.149.0), затем `npm run build` → `dist/el-sueno.html`.
- `build.js` склеивает `src/shell.html` + `three.min.js` + `src/{data,audio,world,systems,screens,game}.js` в **один** HTML без внешних зависимостей. Порядок файлов важен: всё лежит в глобальной области, модулей нет.
- Результат открывается двойным кликом (`file://`), сервер не нужен.

## Архитектура (`src/`)

| Файл | Содержимое |
|---|---|
| `shell.html` | HTML-разметка, весь CSS, плейсхолдеры `/*__THREE__*/` и `/*__GAME__*/` |
| `data.js` | Контент: `ZONES`, `ITEMS`, `DOCS` (тексты документов, некоторые зависят от флагов), `LEX` (76 слов с определениями на простом испанском), `ARCHIVE` (лор с типом «hecho / testimonio / hipótesis»), `ECOS`, символы и решение загадки |
| `audio.js` | `AudioManager` — весь звук процедурный (Web Audio): дроун, ветер, гул, радио, слой угрозы, SFX; озвучка через `speechSynthesis` (es-ES) |
| `world.js` | Процедурные текстуры (canvas), `SceneManager` (геометрия всех 5 зон, свет, интерактивные объекты `addInter`), `CAMS` и `CameraManager`, `Player` (модель героя), `Gfx` (рендер в низком разрешении + пост-шейдер: зерно, виньетка, аберрация) |
| `systems.js` | `SaveManager` (localStorage + валидация), `LanguageSystem` (подсветка слов, словарь), `Inventory`, `LoreArchive`, `DialogueSystem` (реплики, выборы, таймер), `PuzzleSystem` (4 плиты), `UIManager` (книга: инвентарь/журнал/словарь/архив/эхо, пауза, тосты) |
| `screens.js` | `SCREENS` — 11 кадров (камера, позиция героя, активные точки, выходы с условиями) и `HotspotSystem` (кружки поверх 3D-проекции, панель переходов) |
| `game.js` | `SCRIPTS` — сюжет: по async-функции на каждую активную точку; класс `Game` (состояние, флаги, переходы, погоня `chaseSeq`, обморок, финал, игровой цикл, ввод) |

Состояние = `state.flags` (сюжетные флаги) + инвентарь, документы, слова, архив, эхо, решения, текущий кадр. `SceneManager.sync(flags)` идемпотентно приводит мир в соответствие с флагами — так восстанавливается сохранение.

## Тесты

`tests/e2e.py` — сквозное прохождение главы в headless Chromium (Playwright): 52 проверки на десктопе и 54 в мобильной эмуляции (`python3 tests/e2e.py m`). Скриншоты сохраняются в `tests/screenshots/`. Прохождение занимает около 10 минут: таймеры погони в тесте идут в реальном времени.

## Технический долг

- Остатки режима с ходьбой: `Player.move` и коллайдеры в `SceneManager`, поля `test` у `CAMS`, `#touch`/`#joy`/`#btnA`/`#btnR` в `shell.html` (скрыты через CSS), `keys`/`joy`/`runT`/`chase` в конструкторе `Game`. Работе не мешают, но их стоит вычистить.
- Всё в глобальной области видимости; переход на ES-модули (с esbuild/Vite) упростит рост проекта.
- В реальном Safari (macOS/iOS) и на реальных Android-устройствах не проверялось.
- Уровни A2–B1 из концепции ещё не реализованы, это задача следующих глав (II — El Hospital).
